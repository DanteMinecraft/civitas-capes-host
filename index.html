CIVITAS / COMMUNITY SERVICES

Civitas Capes

A lightweight cape data service for Minecraft clients using the Civitas Capes mod. This host provides the cape catalog, player assignments, and cape texture files.

Static host is responding HTTP

Cape catalog

Definitions of the capes clients can load.

/capes.json

Player assignments

UUIDs, active capes, unlocks, and cape settings.

/players.json

Cape textures

PNG textures referenced by the cape catalog.

/capes/

Configure the mod

Set the client config URLs to the public HTTPS URLs for this host.

capeCatalogUrl = https://YOUR-DOMAIN/capes.json
playerDataUrl = https://YOUR-DOMAIN/players.json
  1. Replace YOUR-DOMAIN with your domain.
  2. Edit capes.json and players.json to match your community.
  3. Upload cape PNGs into the capes/ folder and reference their public URLs in the catalog.
Civitas Capes is a community-hosted service. Only publish player data and assets you are authorized to share.
